LOBBY JOIN PATH OF AA.EXE (private join messages, session snapshot, PlayerJoin decree)
==================================================================================

Port: crates/aa-netcode/src/lobby.rs. Oracle: research/phase8-net/native_lobby.py ->
native-lobby.json, replayed by crates/aa-netcode/tests/lobby.rs. Every case runs on the
original image and on v14 (.text/.rdata overlaid); results and every executed byte window
are identical in v14 (native-lobby.json v14_result_differences = [], executed_windows all
v14_identical). The v14 runtime does not patch any of these functions.

PlayerJoin decree 0x758FD0 on the host only:
  +0x88 = 1; 0x752300 ResetBackupSendersToClient; 0x752490(AdminNode+0x218)

2. ADMIN STATE (kind 0) ---------------------------------------------------------------------
Writer 0x74C130 (this = AdminConn): 1 bit 0; address of the conn (vfunc 0 0x74B4E0 =
[conn+0x414]+0x9C, 0x76A7C0: ip, port as two 32-bit words, 0/0 for null); AdminNode +0x200,
+0x204; 0x765F10(AdminNode+0x208) = SessionPlayer id or 0; +0x28C admin time (binary32 bits);
+0x218 next decree packet; synchronizer A 0x77CBE0 (= window end - 1) and 0x573580 (hash).
Reader 0x74DF50 writes AdminNode +0x29C (0x76A810: interned address or null), +0x248, +0x24C,
+0x250 = 0x76B8F0(id, film 0) (first player with that id that is not a film player, else
null), +0x28C, +0x20C; 0x77D900(index, hash) on synchronizer A (enabled, file dump, hash,
window [index+1, index+1)); client clock (AdminNode+0x16C, vtable 0xA91AB4, ctor 0x75FAA0)
virtual +0xC 0x75FAC0(f32(time - 0.0625), 0.0625): period, offset = f32(now - start), all 32
samples = offset; +0x158 = &+0x16C; then 0x75FB40(fstp f32(fild(+0x218 - +0x20C - 1) *
0.0625 + time)): offset = max(sample0, -9999999.0) (x87 compares, NaN keeps), sample1 =
sample0, sample0 = f32(now - target), offset = sample0 when offset <= sample0 or unordered.
The target statement is precision dependent (fmul + fadd); PC24, PC53 and PC64 (when the f64
sum is exact) are ported and oracled.
Note: the admin-state message's +0x200/+0x204/+0x208 are copied to the client's
+0x248/+0x24C/+0x250 = aa_orders ClientState resume_byte / resume_bit / field_250; +0x250 is
a SessionPlayer pointer (the decree stream's current SetPlayer player).

Map settings 0x512CB0: world conditions +0x20 (0x511BB0 / 0x512070) first, then the map
header +4 (0x50E200 / 0x510D90), +0x3C, +0x40, +0x44 (0xB3AA24), +0x48 (0xB3AA34), +0x4C.
Definition references: writer sends def+0xC or the registry count for null; reader
0x411FA0(count + 1) (a value above the count is a native assertion) -> array entry for an
index below the count (object definitions additionally need virtual +0x38, 0x76A960),
otherwise null. World rules: the reader reuses one temporary {null, 1, 0}: a kind that does
not serialize a value keeps the previous entry's value; a bool replaces only the low byte

(+0x3C, +0x40, +0x38, +0x18, +0x1C, entries +0x44) exists only for version (+0xC) > 1; a
reader with version <= 1 keeps the previous extended fields.

5. CAPS -----------------------------------------------------------------------------------
  0xB408F4 static message stream, 0x400 bytes initial (0x7535CD) -> WireWriter (growable).
  Player list / vectors / property table: native linked lists and doubling vectors, no cap;
  Rust Vec bounded on input only by the remaining packet bits (and a caller budget for
  zero-width definition lists).
  Session max players (+0xD4) and the 3/4/2-bit wire fields are protocol rules, kept.
  Client clock 32 samples (0x75FAA0): fixed native layout, only samples 0/1 are used; kept.
