`native-finalize.json` executes original and v14 `776B20` in 96 cases across
the three x87 precision controls. It proves the ordinary game-type2 suffix:
the current Session100/RNG seed, reverse parameter31/32 writes, and current
MULTIPLAYER/DynamicCampaign rules. Its explicit F8=13 bypasses the separately
proved implicit-AI prefix. ScenarioFind in that fixture is a named transport
seam; the fixture does not prove the application's resource manager.

The Rust caller now joins the real source-backed paths: diagnostic, actual
implicit-player publication, same application ScenarioFind/cache open-close,
same selected Creator source+50, RNG/seed, parameter stores and rule setters.

order, old byte32 on the unassigned branch, and the31 store before a reached
AI getter failure. It does not synthesize players or read copied SessionFacts.

The focused parameter replay passed both tests in `rust01.log`; the actual
three-map cache replay passed before the process-counter extension. A new
combined actual-source replay passed both integration tests in `source01.log`,
including three actual maps and real Windows/selfHost→queued-task publication.

tree run; this earlier produced-binary checkpoint is not silently recertified.
`finalize_host_suffix_after_implicit` deliberately certifies only the suffix
for existing research callers; it does not claim to reorder their earlier
diagnostic into the full native procedure.

`launch_ordinary_host_77a950` uses the existing shared native launch kernel on
the actual retained owners. It requires the real launch-subobject dump, then

fake callback nor returns a battle activation. Queued resource work may remain

worker schedule. The authoritative E4/F8 remain their sole u32 fields; a
briefly considered Atomic migration was reverted before final integration.
