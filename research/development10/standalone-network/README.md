# Fresh local standalone service

This port supplies the genuine fresh offline branch needed before human player
glyph selection. It does not implement an Internet service or certify mission,
AI, lobby, transport, or multiplayer readiness.

`ScopedManagedLoad::select_local_offline` is an explicit once-only choice in the
existing fresh application owner. It runs native785560's three real constructor
projections and carries the same allocations through `InactiveLoad` into
`StartupOwner`. An unknown scope, an unselected choice, and an incomplete or
failed constructor refuse the online-manager-presence read. A second selection
also refuses, including after an error. There is no public constructor accepting
an invented online/offline boolean or adopting a previous Internet manager.

Native785560 leaves B40C9C unchanged. Its absence follows only from this fresh
application scope and the loader-zero word proved in both images; it would be
wrong to use this service to clear an existing Internet account manager. The
native proof includes a nonzero prior word to make that distinction visible.

The three children retain the reached native fields rather than initializing
unwritten bytes as zero:

- 79A670 publishes the browser owner, starts its real timer, clears+14, and
  copies the current `GameSpySBThinkPeriod` integer to+10.
- 7988F0 publishes the query owner, clears its reached fields in order, starts
  a separate timer, converts current `GameSpyQR2ThinkPeriod` with FILD/FSTP to
  binary32+14, and performs all thirteen8ADA60 registrations50..62.
- 79AB30 publishes the hash owner with997 buckets, size0 and enabled1, allocates
  the native-sized bucket array, and clears every bucket. This initial hash
  capacity is not an artificial gameplay or networking limit.

Both current period variables are bound from the actual root UVars wildcard
sources with declaration spans, file hashes, and assignment order. Profiles,
console overrides, inherited VarHash nodes, and unsupported literal forms need
their actual owners. The shipped QR2 integer50 is exact in binary32. A custom
integer requiring rounding is explicitly refused by the production binder until
the actual live rounding-control owner is provided; the private native fixture
still proves integer extremes under declared round-to-nearest PC24/53/64.

`WindowsStandaloneClock` samples the actual Windows QPC and shares the existing
process QPF initialization with `PerformanceTimer`. Each child owns its own raw
anchor. No elapsed-time zero, simulation clock, or RNG substitutes for QPC.
Undefined native integer timer divisors/overflow are refused. Native59AA70/
59AB60 and their CRT arithmetic run in the oracle; their platform outputs are
named explicit inputs there. The retained Rust timer projection is not a claim
to port every native global timer optimization or every Windows failure mode.

The proof has126 rows in original/v14 at all three x87 precisions. It executes
785560, all three children, timer arithmetic and the actual key table stores.
It covers nullable outer allocations, required cutoffs, partial publications,
integer conversion boundaries and a preexisting online word.302 executed native
instruction pins match both images and decode independently. The actual
7876F0-created functor's vtable+4 points to785560; its thread queue, lock,
dispatch timing and old-service destruction remain outside this fresh scope.

Production uses successful Rust allocation. Allocation failure/unwind parity,
invalid native aliases, reentrant allocation/platform callbacks and native SEH
cleanup are not claimed. The QR2 table projection owns only registrations50..62;
other IDs require their real prior table owner and cannot be read as absent.
An external required cutoff is not a simulated C++ exception.

Before-file copies preserve the lifecycle and Windows source. Prior failed logs
remain retained. `tests-v1.log` was blocked by another in-progress glyph module
(missing fixture and a corrected field spelling), not a passed test run. Final
test and source hashes are recorded separately when verification finishes.
