Implemented
- Source binder uses the canonical Thing declaration's source directory and ordered original View aspects; AspectNormal precedes Aspect rows when variations are disabled. Ordinary native variant -1 selects that normal aspect. Constructor variations use their actual nonnegative index. State/construction overrides must arrive as an already resolved native aspect index, never Actor+15C's state index. Unsupported nonvariation positive variants without that explicit resolution fail.
- Model expressions use native resource_prefix + aspect_prefix substitution; an absolute aspect prefix or model path bypasses the current resource directory. No inspector first-model, guessed filename or absent-resource fallback. Existing source-bound model material/visibility audit and UV conversion apply before GPU upload. Every source binding retains original field/declaration provenance.
- All five original infantry factions and their normal/kneeling/prone aspects bind and load original NIFs. The exposed binding is read-only after preparation.
- Renderer shares upload preparation between replacement and append. Append stages new GPU resources with the renderer's own layouts, then publishes only on validation/scope success. Existing GPU resources, posed vertices, dynamic bounds, slot indices, picking objects, and scene epoch are retained. New meshes currently own their own buffers/material bindings/textures; this does not claim cross-actor asset deduplication.
- Picking geometry and the native ActorId binding stage before GPU acceptance and publish afterward. Duplicate/full-generation IDs, malformed resources, invalid transforms, incompatible draws, and stale epochs fail without observable prior-scene replacement. New actors support the existing transform/team-color/visibility snapshot API immediately after append.
- Append invalidates transparency command/bundle caches; existing per-instance material masks and original native sorting remain active. Publication order appends new actors after the initial source traversal. Original engine scene insertion order is not yet proven.

Limits and integration contract
Root main/runtime still supplies actual registration, active native state selection, owner/team color, visibility, authoritative pose/scale, and snapshot timing. This gate alone does not create simulation actors or prove a playable match. Only retained static model geometry is appended; dynamic event-selected KF playback, model switching after state changes, actor resource removal/reuse, pitch/roll, native picking masks, FX/shadow/water parity are separate work. Source skin/glow/TextureRename overrides are explicit unsupported errors instead of silently using the wrong material. Original gameplay, saves and existing releases are not modified. GPU device loss/system allocator failure is outside a transactional rollback guarantee. Source conversion/source metadata limitations established earlier remain.
