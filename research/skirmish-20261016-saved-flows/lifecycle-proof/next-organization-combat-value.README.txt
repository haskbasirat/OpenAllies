  owns aa_actors::ground_states::OrganizationState<String>. Avoid manufacturing
  a general live Organization full of unrelated defaults or cloning/replacing
  the member/component world to satisfy the broad organization::World trait.
  Its combat-value path only reaches member_count/member/member_combat/
  slot_definition; unrelated World methods should remain explicit errors.

  Preferred future change: factor the already-proven sum into a narrow borrowed
  output/read interface shared by the existing wrapper and saved adapter, so
  each native+68/+6C store updates the actual org.words immediately. Preserve
  all native arithmetic and existing oracle coverage; add owned-adapter proof.
  A two-output projection is a bounded alternative ONLY if both outputs are
  committed on every Result path, including errors, and no reentrant getter
