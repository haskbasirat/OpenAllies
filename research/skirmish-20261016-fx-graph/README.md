# Created FX compilation and event construction

`fx_graph` separates source inputs from completed native command definitions.
Only the private source-bound producer creates a `Graph`; a failed loader
returns its owned `Draft` with earlier allocations, stores and child/root
prepends preserved. The native42B990 parent list receives a command only after
its entire loader has returned. Each authored occurrence is a distinct command.

The admitted loader is CREATE_VFX0:42AEF0 construction,42BF10 list traversal,
42C1B0 common fields and42C5E0 VFX fields. Immediate chains precede ordinary
chains, both prepend. Target bits commit per token. Health clamping, selected
enum values, cutscene rejection, location, coordinates, duration predicate and
the attached-position warning/fixup retain native ordering. The first raw VFX
IDS in the reference context is remembered without replacing distinct nodes.
Scalar and point getters explicitly admit finite binary32 inputs only.

The source binder uses current immutable Bank source precision, actual inherited
nodes, canonical VFX identities and source-file/root positions. It applies only
one-hop translations whose roots were already processed at the owner's load
position. It does not consult a possibly later final translation. Bone uses its
distinct mode0 manager:486650 starts count0,486870 writes current count to
Data+C before93D4E0 appends that same allocation. Bone source roots are ordered
by actual source-file order and span. A reached predefined ActorState ordinal
still requires its dedicated source producer. Non-Created lists are refused
until their shared earlier-list reference context is bound.

Native fixtures explicitly replace typed file getters, enums, registry lookup,
allocation and string transport. The command constructors, recursive traversal,
list mutation and field stores execute unchanged in original and v14, at all
three x87 precision settings. Separate native fixtures execute enum-registering
callers and the Bone count/ordinal producer; those fixtures name their string,
reserve-element and successful-lookup transport seams. They do not claim full
file loading or rendering from an arbitrary fixture registry answer.

`Command` is opaque, owned and non-Clone, with no public placeholder constructor.
4296B0 gates empty then muted before reading its current Thing.428F40 obtains
the actual creator Kingdom. The constructor copies current target then source
coordinates and IDs, and compares actual current OS thread ID to retained
MainThread+48 to select View+8C or World+E0. Its embedded FXL is parented to
this same event; the final argument is NULL, so624100->45C740 returns with its
constructor-null definition. Queue submission50C800 is the caller's next
operation and has separate `fx_manager` proof. No effect instance has executed
merely because this complete event exists.

The live worker/App OS-thread owner and View clock remain required until their
native producers are integrated. Neither precision nor a guessed role selects
a clock. PLAY_SFX, EQUIPMENT, CREATE_RFX and other FXC constructors/loaders remain
explicit required boundaries; earlier supported nodes retain their real prefix.
Model/audio/resource execution, presentation drain and complete game parity
are separate work. These bounded proofs do not certify a complete playable
battle or multiplayer. Original game and release files are untouched.

All native generators replay immutably by default; `--write` explicitly
regenerates author fixtures. The source census is an explicit ignored test
using original/v14 assets. Its output records both successes and required
boundaries and must not be presented as full source compilation.
