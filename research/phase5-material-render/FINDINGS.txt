PHASE 5: ORIGINAL MATERIAL STATE

The old static conversion retained only alphaBlend and a threshold. It lost
source/destination blend factors, alpha comparison functions and independent
depth-buffer writes. The preview then used conventional alpha blending for
every blend material and disabled all their depth writes.

This was an actual authored-data mismatch on the reported Crete map:
- MediterraneanCityCenter01/Mesh01 uses alpha flags 193: ONE/SRC_ALPHA.
- MediterraneanFarm01/Village02 uses flags 4845, threshold 150, Z flags 3.
- ChaparralVineyard meshes mix Z flags 3 (write) and 1 (read only).
- Dirt roads use normal source-alpha blending and read-only depth.
The wheel-like models in the screenshot are audio-source editor markers,
investigated separately under phase5-scenegraph; these were not lost bodies.

The source-bound sidecar now retains inherited NiAlphaProperty flags/threshold
and NiZBufferProperty flags/function for all 1847 models / 11035 exported meshes.
Original/recovered model files and prior release sidecars remain unchanged.
Default alpha 236 and Z 3/3 are supported by native constructor instructions.
RepColor still suppresses alpha blend/test as recovered in phase 2, preserving
replacement-color masks. Material-opacity alone no longer enables blending
when authoritative NIF flags are available. Legacy sidecars remain readable.

The renderer creates pipelines for the authored RGB blend factors and depth
state. WGSL evaluates all eight authored alpha comparison modes. The opaque
scene target is presented with alpha 1; shader alpha still controls color blend
factors and cutout tests. Destination-alpha-dependent blend factors are rejected
explicitly until a separate internal-alpha target is implemented; the entire
retained non-team-color original mesh corpus contains zero such factors.

Limits:
This is static authored material parity on an opaque Z-buffer target. Native
sorting, per-triangle ordering, W-buffer mode, alpha-controller animation,
dynamic game-state material overrides, complete native shader stages,
illumination and color-space parity remain unfinished. Cutout filtering and
float comparisons use the modern GPU and are not claimed bit-identical to D3D9.
The test fixtures establish state choices, not a running original match.
