# FXC derived source fields

`findings.json` seals the concrete constructors and source loaders for native types 2, 4, 5, 6, 7 and 9. Their common loader, list/reference topology and previously proved types 0, 3 and 8 remain shared. Native factories no longer produce the incomplete laboratory `RequestOnly` variant.

The controlled oracle covers 279 cases, each executed separately against original AA and v14 at all three precision settings (558 executions, 1,086 executed instruction pins). Getters, enum/source references, CString allocation and Texture resource/policy operations are explicit transports. The derived stores, native colour conversion and virtual predicates execute. This proves source fields in the admitted finite and successful-allocation domains; it does not prove effect execution, GPU rendering or playable battle.

`exact-subtypes-tests.exe --include-ignored --nocapture` replays seven exact-source tests. Set `AA_GAME_ROOT` to the installed game directory. The actual-source test compiles four Equipment nodes from three installed units; that source test is distinct from the controlled native cases. Run `native_fxc_subtypes.py` without `--write` for an immutable native replay. Pins and exact source extraction are recorded in `findings.json` and `exact-source-pins.json`.

Positive type 6/7 Texture fields deliberately require the actual manager-owned Resource and current policy callbacks. The source-only compiler cannot manufacture a resource identity. The next resource-aware binder is a separately qualified successor, using the same source session and ResourceManager. Positive runtime subtype effects remain required at their reached boundary.

The `before/` directory contains contemporaneous copies of the five listed parent/test files. The sound module's one added empty Texture map initialization did not have a contemporaneous copy in this task; no reconstructed preimage is represented as an original capture. Failed prototype logs are retained, including the initial colour-order mismatch corrected using the native oracle.
