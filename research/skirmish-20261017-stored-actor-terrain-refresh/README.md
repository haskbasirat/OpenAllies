# Shared held and stored Actor terrain refresh

`actor_terrain_fields` is one `4D4130` transition kernel. The prior held API
delegates to it, and `stored_actor_terrain_refresh` lends current ActorAccess,
Arena, source Bank, terrain, spatial storage, variables, clock, inventory and
Property State. The actual F8 store precedes Organization recursion and Property
effects. Recursion rereads current member slots in native order and requires the
real child Element; cycles remain an explicit portable refusal.

Terrain lookup uses the current placement owner's cached cell, or the actual
eligible Element parent's F8. The same native source registry/provenance and
source precision authorize TerrainData and linked Property identities. Removal,
eligibility and insertion reuse the actual stored Property services, with native
kind 5 and self as source. A true empty effect owner returns before unrelated
instance-definition compilation through the shared `remove_reference` entry.
No instance arena, Actor shell or component table is copied or replaced.

The original held source was backed up before factoring. The old native fixtures
remain unchanged. `property-callback-arguments.json` is a static both-image byte
check, not new native execution. `exact-field-tests.exe` compiles the exact pure
production source with pinned existing dependencies and replays all 186 native
outcome/F8 rows. This establishes those observable prefixes; it does not turn
the fixture's required child boundaries into successful child implementations.

The actual stored laboratory uses the real Kursk source/map and moved diagnostic
Actor 11631. It explicitly controls active gate bits and seeds cached coordinates
from that actor's saved pose because diagnostic Load omits Object Init. Its real
grid/tile constructor has no registered actors; placement reads use the original
staged actor owner. It proves same allocation/F8 and actual Terrain source lists
across three live precisions, including an `arctic_city` prior list with an actual
empty Properties owner. It does not prove published actor membership, positive
Property mutation, Organization recursion, natural fresh initialization, complete
World startup or playable battle.

Settlement `585650` remains required. RuntimeComponent has no typed Settlement
owner. Native inspection shows reverse traversal of its two actual actor vectors
and an optional actor, with aggregate `4D0180/4D01E0` children and immediate
`+30/+34` stores. The earlier source census reported no shipped Settlement
factories; this work does not create an empty component to claim that path.

Final execution/source pins and the independent review are recorded in
`findings.json` after the current-source retry has completed. Intermediate
capture/log files are retained separately.
