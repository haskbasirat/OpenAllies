Packaging and preservation
The packaging script requires the successful final logs, exact executable hash,
review reports and unchanged asset-cache hashes. It creates a new Development04
folder, records per-file SHA256 hashes and validates every ZIP payload and CRC.
The copied executable receives a separate smoke check after packaging. Package
and smoke reports are recorded in qa-output/phase4.

Original/v14 executables, save files, profiles and prior release folders were
not edited. The source was backed up before this pass. Original assets are read
only; temporary negative-test data is separate. Existing preview windows were
not closed or controlled. Checks were headless or isolated source/fixture tests.

Remaining limits
The executable is still an asset/development preview. No complete match,
pathfinding/world integration, full combat/AI, campaign/strategic mode, original
save compatibility or real multiplayer session was tested or implemented by
this pass. Internet tests across separate PCs/connections remain unavailable.
Live laptop/multi-monitor UI tests were not repeated. Earlier render fidelity
gaps remain open, and no general gameplay performance improvement is claimed.
