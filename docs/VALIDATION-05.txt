Limits
The screenshot defects have specific verified fixes; this is not complete
native visual parity. No identical-camera original-game pixel reference was
captured. Backend images are visually consistent but not byte-identical. Native
water, terrain composition, road draping, lighting/shadows, LOD, transparent
sorting and dynamic material behavior still require work. Unknown authored
visibility expressions/definitions are retained and reported rather than guessed.

No full playable match, native save/replay compatibility, complete combat/AI,
campaign/strategic mode or real multiplayer session is claimed. Internet tests
across separate PCs/connections remain unavailable. Live laptop/multi-monitor
GUI tests were not repeated; headless and source/GPU tests are distinguished.
The preview package requires the existing recovered original assets and source
data. It is not a standalone whole-game distribution. Original/v14 executables,
saves/profiles and Development 01–04 packages were not edited.
